# Published verification artifacts

This directory contains a curated Mind2Web-derived verification run set that
is intentionally included with the public repository. The web application
discovers these JSON files alongside locally generated runs.

The published set contains per-requirement predictions, evidence references,
and normalized bounding boxes for all 13 numbered flows. It does not contain
screenshots, HTML, OCR text, full screen summaries, raw provider responses,
model caches, API credentials, or absolute local paths. Email-like task values
and the associated example name were redacted from retained evidence text.

Mind2Web attribution and the redistribution boundary are documented in
[`../../NOTICE.md`](../../NOTICE.md) and
[`../../docs/dataset_licensing_and_release_policy_2026-07-23.md`](../../docs/dataset_licensing_and_release_policy_2026-07-23.md).
These derived artifacts are not covered by the repository's MIT code license.
