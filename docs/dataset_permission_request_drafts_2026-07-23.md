# Dataset Permission Request Drafts

These messages are prepared but have not been sent.

## Mind2Web maintainers

**Subject:** Permission clarification for derived annotations from Mind2Web test trajectories

Dear Mind2Web maintainers,

I am using 13 trajectories from the `test_task` split in a Bachelor's thesis at
the Technical University of Munich. I created new UI-requirement text,
four-class verification labels, claim annotations, and aggregate evaluation
results from the ordered screenshot flows.

I understand that the Mind2Web dataset is identified as CC BY 4.0 and that the
repository additionally asks users not to redistribute unzipped test files
online or include benchmark data in training corpora.

Could you please confirm whether I may publicly release the following derived
artifacts with full attribution and a no-training notice:

- author-created requirement text and verification labels keyed to 13 test
  annotation IDs;
- evidence step numbers, but no screenshots, HTML, MHTML, HAR, video, task
  records, or raw trajectories;
- aggregate metrics, configurations, hashes, and evaluation code?

If the per-item derived annotations should not be public, I will release only
code and aggregate results and keep the detailed artifacts available to the
examiners under controlled access.

The existing project repository is:
<https://github.com/benno-tum/ui-requirement-verification>.

Best regards,

Benno Brueck
## PURE curator

**Subject:** Permission clarification for derived annotations from PURE documents

Dear Dr. Ferrari,

I am using limited material from the PURE dataset in a Bachelor's thesis at the
Technical University of Munich, primarily the documents identified as
`2010 - split merge` and `2010 - mashboot`.

The Zenodo record notes that the individual requirements documents were
collected from public Web sources and that their underlying license or
intellectual-property status is not known. I therefore plan to exclude the
source PDFs, XML files, extracted figures, screenshots, and substantial text
extracts from the public replication package.

Could you please clarify whether I may publish:

- author-created UI-verification labels and claim annotations that include the
  full requirement sentence;
- source document, page, and section identifiers;
- aggregate metrics, hashes, extraction code, and evaluation code?

If reproducing requirement sentences is not covered, I will publish only
document/section identifiers, non-textual labels, aggregate results, and code,
and require users to obtain PURE independently through Zenodo.

Best regards,

Benno Brueck
